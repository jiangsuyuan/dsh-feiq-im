# 飞秋式局域网 IM（dsh-feiq-im）

## 它是什么

一块常驻在 **DSH 工作区右侧**的聊天气泡：有人发消息，右上角出现红点数字；点开就能看到谁发了什么、发了几条，再点进去聊天。收发走标准 **IPMsg** 协议（UDP 2425），所以同网段的**飞秋**、**飞鸽传书**用户不需要装这个插件也能和你互发文字、图片，也能互相闪屏震动。

## 怎么用

1. 进 **Plugins** 启用后，右侧出现一个圆形气泡（无未读时只有图标）。
2. 同网段的飞秋 / 飞鸽会自动出现在列表的「在线同事」里，**不需要添加好友**，点一下就能发消息。
3. 有未读时气泡右上角显示数字；点开面板，未读会话置顶。
4. 自己发的每条消息下面有状态：`…` 发送中、`✓` 已送达、`✓✓` 已读、`!` 失败可点重试。
5. 面板里点「抖动」可以给对方闪屏；收到对方的抖动时气泡会震动。

## 启动时的 2425 端口检查

飞秋与飞鸽默认都占用 UDP/TCP **2425**，本插件也用 2425。若本机飞秋正在运行，面板顶部会出现提示，提供`关闭飞秋并启用` / `仅用本插件网络` / `稍后`。关闭动作只对"占用 2425 且进程名匹配飞秋"的进程生效，需要二次确认，退出 DSH 时可选自动恢复飞秋。

## 已知限制

- 明文传输：与飞秋一致，同网段抓包可见，不要传凭据。
- 不实现飞秋的加密会话：不回应公钥请求，因此双方保持明文（已验证）。
- 群聊、文件夹传输、远程协助不在本版本。
- 接收飞秋的 `LZW!` 图片会先保存为 `.bin`，JPEG 图片可直接显示。
